What it does

When you visit X or Twitter in Firefox, Twitterviewer redirect sends supported pages straight to TwitterViewer.net so you can read them without an account. It covers:

  • Posts: x.com/<handle>/status/<id>, including photo/video suffixes and /i/status/ links.
  • Profiles: x.com/<handle>.
  • Hashtags: x.com/hashtag/<tag>.

It works on x.com and twitter.com, including www. and mobile. subdomains, and preserves your original URL, query string, and hash so the right post is opened. Navigation pages such as Home, Explore, Search, and sign-in are left alone.

Privacy

This extension collects no personal data and declares no data-collection permissions ("data_collection_permissions": { "required": ["none"] }). It runs entirely in your browser and only rewrites navigation URLs matching x.com and twitter.com — it never sees or stores the page contents.

Only top-level page navigations are redirected (types: ["main_frame"]); images, scripts, and API calls are untouched. TwitterViewer.net itself is never redirected, so there is no redirect loop.

FAQ

What is this extension?

Twitterviewer redirect is a small Firefox extension that sends X/Twitter posts, profiles, and hashtags to TwitterViewer.net automatically, so you can view public content without signing in to X.

Which Firefox version do I need?

Firefox 140 or newer (Firefox for Android 142 or newer).

Why is Home or Explore not redirected?

Those pages are app navigation, not viewable content. The extension only redirects posts, profiles, and hashtags — the same set supported by TwitterViewer.net.

Does it work on twitter.com too?

Yes. x.com and twitter.com (including www. and mobile.) are both covered.

Where can I get help?

See the Help & Support page for troubleshooting and contact details.

Is it free?

Yes, free and open source.
