Installation

Twitterviewer redirect is a Firefox extension. It requires Firefox 140 or newer (Firefox for Android 142 or newer).

Install from Mozilla Add-ons

  1. Open the Mozilla Add-ons listing.
  2. Click Add to Firefox and confirm the install.
  3. Open any supported X/Twitter post, profile, or hashtag. It should open on TwitterViewer.net.

Download the extension

Firefox keeps the extension updated automatically. You can manage or remove it at any time in about:addons.

Links are not redirecting at all

Check these in order:

  1. Confirm the extension is enabled in about:addons and is not blocked.
  2. Confirm Firefox is version 140 or newer (Menu → Help → About Firefox).
  3. Test with a direct link such as https://x.com/NASA. Home and Explore pages are intentionally not redirected.
  4. Other privacy or redirect extensions may conflict. Disable them temporarily to test.
Some X/Twitter pages still open on X

The extension only redirects content pages: posts, profiles, and hashtags. Navigation pages such as Home, Explore, Search, Notifications, Messages, settings, and sign-in are left untouched. Posts with unsupported URL shapes can also be skipped. If a content link does not redirect, send us the exact URL using the contact form.

Does it work in private windows?

Only if the extension is allowed in private browsing. Open about:addons → the extension → Details and enable Run in Private Windows.

Why does the address bar briefly show x.com before TwitterViewer.net?

The extension intercepts the navigation before the X page loads, but Firefox may display the requested address for a moment. No X content is loaded by the extension, and your browser is then sent to TwitterViewer.net with the original link attached.

Will it redirect links inside TwitterViewer.net?

No. TwitterViewer.net is never redirected, so there is no loop. Only top-level navigations to x.com and twitter.com hosts are rewritten.

Does it redirect images, videos, or API requests?

No. Only main-frame page navigations are processed. Images, scripts, stylesheets, and background requests are untouched.

Can I use it with Firefox for Android?

Yes, on Firefox for Android 142 or newer, subject to Firefox for Android's extension support. Installation and behavior may differ from desktop Firefox.

How do I uninstall it?

Open about:addons, find Twitterviewer redirect, open its menu, and choose Remove.

Privacy

The extension collects no data and declares no data-collection permissions. It runs locally in your browser, rewrites only eligible navigation URLs, and never reads page contents.

This help site is separate from the extension. Contact form messages are sent by email to the maintainer and include only what you type. No analytics or advertising scripts are used.
